# 📸 App Store Screenshots Guide for Poker Manager

## Quick Start (5 Minutes)

### Step 1: Prepare Your Simulator
```
1. Open Xcode
2. Click on simulator dropdown (top left, near Play button)
3. Select: iPhone 16 Pro Max
4. Press ⌘R (Command + R) to run your app
```

### Step 2: Take Screenshots
```
1. Navigate to the screen you want to capture
2. Press ⌘S (Command + S) in the Simulator window
3. Screenshot automatically saves to your Desktop
```

### Step 3: Find Your Images
```
📁 Location: Desktop folder (~/Desktop/)
📄 File names: "Simulator Screen Shot - iPhone 16 Pro Max - 2026-03-31 at 14.30.45.png"
```

## 📤 Uploading to App Store Connect

### Step-by-Step:

1. **Go to App Store Connect**
   - Visit: https://appstoreconnect.apple.com
   - Sign in with your Apple Developer account

2. **Select Your App**
   - Click on "My Apps"
   - Choose your Poker Manager app

3. **Navigate to Screenshots Section**
   - Click "App Store" tab (in the left sidebar)
   - Scroll down to "App Previews and Screenshots"

4. **Upload Screenshots**
   - Find "6.9-inch Display" section
   - Click the "+" button or drag files from Desktop
   - Upload 3-10 screenshots
   - Arrange them in order (drag to reorder)

5. **Add Descriptions (Optional)**
   - Click on each screenshot
   - Add a description for accessibility
   - Example: "Track active poker games and player buy-ins"

6. **Save Changes**
   - Click "Save" at top right
   - Your screenshots are now uploaded!

## 🎨 Pro Tips for Beautiful Screenshots

### Before Taking Screenshots:
- ✅ Use realistic player names (Sarah, Mike, David, etc.)
- ✅ Show varied amounts ($200, $350, $150)
- ✅ Ensure your app is in Dark Mode (looks better)
- ✅ Hide or minimize any debug info
- ✅ Use Time = 9:41 AM (Apple's marketing standard)

### What Makes Great Screenshots:
- 📱 Clean, uncluttered interface
- 💰 Show realistic pot amounts ($500-$2000)
- 👥 Show 4-8 players (realistic poker game)
- 📊 Display charts/graphs if possible
- 🎯 Feature your best UI elements

### What to Avoid:
- 🚫 Empty states (unless showing onboarding)
- 🚫 Error messages
- 🚫 Personal information
- 🚫 Placeholder text like "Lorem ipsum"
- 🚫 Screenshots with blurry or pixelated content

## 🔧 Troubleshooting

### Problem: Screenshot is wrong size
**Solution**: Make sure you're using iPhone 16 Pro Max simulator

### Problem: Can't find screenshots
**Solution**: Check Desktop folder, or check Xcode DerivedData folder

### Problem: Screenshots look dark
**Solution**: That's normal! Your app uses dark theme, which looks professional

### Problem: App Store Connect rejects my screenshots
**Solution**: 
- Check file format is PNG
- Verify exact dimensions (1320 × 2868)
- Make sure screenshots are in portrait orientation
